## 已实现

- 黑色主界面、顶部日期胶囊、底部“记账”主按钮和三个圆形入口
- 日期横向滑动查看以前日期、日期切换、月份小弹层
- 点击“记账”弹出快速记账面板，可在支出/收入之间切换
- 支持输入类似“海底捞 422”或“工资 5000”，识别金额、备注和分类
- 确认后在日期和“记账”按钮之间显示当日单次记账详情
- 明细页支持切换到过去日期补记漏掉的账单，补记记录会落到选中的日期
- 明细页显示选中日期的收入、支出和结余汇总
- 月历明细支持直接切换上一个月、下一个月或回到本月，可快速查看过去月份的每日明细和当月汇总
- 明细页与资产页共用币种设置，可在首页直接切换人民币、美元等 10 种币种；金额会同步换算显示
- 在明细页选择某币种后，新记账输入会按该币种理解，并统一换算为基础金额保存，避免切换币种造成累计误差
- 记账时可将记录计入“项目”，用于旅行、活动或长期计划
- 项目支持名称、开始/结束日期和可选预算；记账面板只显示覆盖当前日期的项目
- 明细页会显示当天所属项目的状态卡，点击可查看项目进度、累计支出、预算剩余和项目明细
- 项目详情中的每笔记录都可单击打开撤回确认，撤回后项目总支出、预算剩余和明细会立即重新计算
- 项目详情支持撤回整个项目；二次确认后移除项目和关联，已记录的收支保留为普通明细，避免误删账目
- 点击某条单次记账详情会询问是否撤回，确认后才删除该笔记录
- 点击“数据”进入数据页，支持支出/收入筛选、周/月/年切换、折线趋势、排行榜和智能报告
- 点击“资产”进入资产页，包含账单、月度预算、资产管家和右上角币种切换
- 确认后写入浏览器 `localStorage`，方便后续页面继续读取
