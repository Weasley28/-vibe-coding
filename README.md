## 已实现

- 黑色主界面、顶部日期胶囊、底部“记账”主按钮和三个圆形入口
- 日期横向滑动查看以前日期、日期切换、月份小弹层
- 点击“记账”弹出快速记账面板，可在支出/收入之间切换
- 支持输入类似“海底捞 422”或“工资 5000”，识别金额、备注和分类
- 支持“单价 × 份数”记账：可用加减按钮选择 1–99 份，也可直接输入“地铁 2.9*2”，自动按 5.8 计入总额
- 首页明细、项目明细和撤回确认会保留显示“单价 × 份数”的计算过程
- 确认后在日期和“记账”按钮之间显示当日单次记账详情
- 明细页支持切换到过去日期补记漏掉的账单，补记记录会落到选中的日期
- 明细页显示选中日期的收入、支出和结余汇总
- 没有支出的日期可以标记“无消费”，支持撤销；月历和顶部日期条会显示绿色状态
- 记账面板支持“金额稍后确认”：可先记下事项、日期、分类和项目，之后点击该笔明细补齐金额或撤回
- 待确认金额的账单不会提前计入收支、预算和项目总额，补齐后自动进入统计
- 月历明细支持直接切换上一个月、下一个月或回到本月，可快速查看过去月份的每日明细和当月汇总
- 首页“月账”入口支持“日历 / 流水”切换：流水按日期分组显示每天的逐笔事项、类别、项目/活动、份数计算和金额，单击记录可打开撤回确认
- 明细页与资产页共用币种设置，可在首页直接切换人民币、美元等 10 种币种
- 币种切换只更改货币符号和显示格式，不进行汇率换算；输入 12 会始终保留数值 12
- 月历每日金额与上方月度汇总使用相同的币种和小数格式
- 记账时可将记录计入“项目”，用于旅行、活动或长期计划
- 项目支持名称、开始/结束日期和可选预算；记账面板只显示覆盖当前日期的项目
- 明细页会显示当天所属项目的状态卡，点击可查看项目进度、累计支出、预算剩余和项目明细
- 项目详情中的每笔记录都可单击打开撤回确认，撤回后项目总支出、预算剩余和明细会立即重新计算
- 项目详情支持撤回整个项目；二次确认后移除项目和关联，已记录的收支保留为普通明细，避免误删账目
- 点击某条单次记账详情会询问是否撤回，确认后才删除该笔记录
- 点击“数据”进入数据页，支持支出/收入筛选、周/月/年切换、折线趋势、排行榜和智能报告
- 点击“资产”进入资产页，包含账单、月度预算、资产管家、数据保险箱和右上角币种切换
- 账目自动写入浏览器 `localStorage`；清理浏览器数据、更换浏览器或本地 `file://` 环境重置时仍可能丢失
- 资产页“数据保险箱”可导出 JSON 备份，并以合并方式恢复记录、无消费日、项目、预算和币种，不会覆盖现有账目
